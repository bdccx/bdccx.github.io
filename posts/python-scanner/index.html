如何用 Python + socket 手写一个 TCP 端口扫描器
#

端口扫描是网络安全学习和日常运维中非常基础的一项技能。它的核心目标很单纯：判断目标主机的哪些 TCP 端口处于开放状态。

这篇文章不依赖 nmap、masscan 这类成熟工具，而是从 Python 标准库 socket 出发，手写一个轻量级 TCP 端口扫描器。你会看到最简版本、多线程加速、命令行参数解析，以及一些实用优化建议。

免责声明：本文仅用于学习与授权测试。请勿扫描你未拥有或未获得明确授权的网络、主机和端口。未经授权的端口扫描可能违反法律法规。

一、TCP 端口扫描的基本原理
#

TCP 端口扫描最常见的方式是 TCP connect 扫描。

它的过程非常接近我们手动连接一个网站：

  1. 客户端向目标主机的某个端口发起 TCP 连接。
  2. 如果目标端口开放，且服务正常监听，TCP 三次握手完成。
  3. 如果目标端口关闭，目标主机会返回 RST，连接失败。
  4. 如果目标端口被防火墙过滤，可能一直超时，或者返回其他异常。

在 Python 中，我们可以用 socket 模块建立 TCP 连接：

import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.settimeout(1)
result = s.connect_ex(("127.0.0.1", 80))
print(result)
s.close()

connect_ex() 与 connect() 的区别是：它不直接抛出异常，而是返回一个错误码。

  • 返回 0：连接成功，端口很可能开放。
  • 返回非 0：连接失败，端口通常关闭或被过滤。

这就是端口扫描器的最小核心。

二、环境准备
#

你只需要 Python 3.6+，不需要安装第三方库。

python3 --version

如果能看到 Python 3.x 版本号，就可以继续。

三、最简版端口扫描器
#

先写一个只扫描单个端口的函数：

import socket


def scan_port(host: str, port: int, timeout: float = 1.0) -> bool:
    """扫描单个 TCP 端口，开放返回 True，否则返回 False。"""
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        try:
            result = s.connect_ex((host, port))
            return result == 0
        except socket.timeout:
            return False
        except OSError:
            return False


if __name__ == "__main__":
    host = "127.0.0.1"
    port = 80
    if scan_port(host, port):
        print(f"[+] {host}:{port} 开放")
    else:
        print(f"[-] {host}:{port} 关闭或过滤")

这个版本已经能判断单个端口，但实际使用中我们通常需要扫描多个端口。

四、扫描多个端口
#

把端口放进列表，然后逐个扫描：

import socket


def scan_port(host: str, port: int, timeout: float = 1.0) -> bool:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        try:
            return s.connect_ex((host, port)) == 0
        except (socket.timeout, OSError):
            return False


def scan_ports(host: str, ports: list[int], timeout: float = 1.0) -> list[int]:
    open_ports = []
    for port in ports:
        if scan_port(host, port, timeout):
            open_ports.append(port)
            print(f"[+] {host}:{port} 开放")
    return open_ports


if __name__ == "__main__":
    target = "127.0.0.1"
    common_ports = [21, 22, 23, 25, 53, 80, 110, 143, 443, 445, 3306, 3389, 6379, 8080]
    result = scan_ports(target, common_ports, timeout=0.5)
    print("开放端口：", result)

这个版本的问题是：如果端口很多，串行扫描会非常慢。比如扫描 1-65535，每个端口超时 1 秒，最坏情况下会等到天荒地老。

所以下一步必须并发。

五、多线程加速
#

Python 有 GIL，但端口扫描属于 I/O 密集型任务，线程在等待网络响应时会释放 GIL，因此多线程仍然非常有效。

使用标准库 concurrent.futures.ThreadPoolExecutor：

import socket
from concurrent.futures import ThreadPoolExecutor, as_completed


def scan_port(host: str, port: int, timeout: float = 1.0) -> tuple[int, bool]:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        try:
            result = s.connect_ex((host, port))
            return port, result == 0
        except (socket.timeout, OSError):
            return port, False


def scan_ports(host: str, ports: list[int], timeout: float = 1.0, workers: int = 100) -> list[int]:
    open_ports = []

    with ThreadPoolExecutor(max_workers=workers) as executor:
        future_to_port = {
            executor.submit(scan_port, host, port, timeout): port
            for port in ports
        }

        for future in as_completed(future_to_port):
            port, is_open = future.result()
            if is_open:
                open_ports.append(port)
                print(f"[+] {host}:{port} 开放")

    return sorted(open_ports)


if __name__ == "__main__":
    target = "127.0.0.1"
    ports = list(range(1, 1025))
    result = scan_ports(target, ports, timeout=0.5, workers=200)
    print("开放端口：", result)

这里有几个关键点：

  • ThreadPoolExecutor 负责管理线程池。
  • as_completed() 让结果按完成顺序返回，而不是按提交顺序。
  • workers 不宜过大，否则可能耗尽本地文件描述符，或者给目标造成过大压力。
  • timeout 要根据网络情况设置，内网可以短一些，公网可以长一些。

六、加入命令行参数
#

一个能用的工具，最好支持命令行传参。用 argparse 解析：

import argparse
import socket
from concurrent.futures import ThreadPoolExecutor, as_completed


def parse_ports(port_str: str) -> list[int]:
    """解析端口字符串，支持 80,443,8000-8100 这种格式。"""
    ports = set()

    for part in port_str.split(","):
        part = part.strip()
        if not part:
            continue

        if "-" in part:
            start, end = part.split("-", 1)
            start, end = int(start), int(end)
            if start > end:
                start, end = end, start
            ports.update(range(start, end + 1))
        else:
            ports.add(int(part))

    return sorted(p for p in ports if 1 <= p <= 65535)


def scan_port(host: str, port: int, timeout: float = 1.0) -> tuple[int, bool]:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        try:
            result = s.connect_ex((host, port))
            return port, result == 0
        except (socket.timeout, OSError):
            return port, False


def scan_ports(host: str, ports: list[int], timeout: float = 1.0, workers: int = 100) -> list[int]:
    open_ports = []

    with ThreadPoolExecutor(max_workers=workers) as executor:
        future_to_port = {
            executor.submit(scan_port, host, port, timeout): port
            for port in ports
        }

        for future in as_completed(future_to_port):
            port, is_open = future.result()
            if is_open:
                open_ports.append(port)
                print(f"[+] {host}:{port} 开放")

    return sorted(open_ports)


def main():
    parser = argparse.ArgumentParser(description="Python + socket TCP 端口扫描器")
    parser.add_argument("host", help="目标主机，例如 127.0.0.1 或 example.com")
    parser.add_argument(
        "-p",
        "--ports",
        default="1-1024",
        help="端口范围，例如 80,443,8000-8100，默认 1-1024",
    )
    parser.add_argument(
        "-t",
        "--timeout",
        type=float,
        default=1.0,
        help="连接超时时间，单位秒，默认 1.0",
    )
    parser.add_argument(
        "-w",
        "--workers",
        type=int,
        default=100,
        help="并发线程数，默认 100",
    )

    args = parser.parse_args()

    try:
        target_ip = socket.gethostbyname(args.host)
    except socket.gaierror:
        print(f"[-] 无法解析主机：{args.host}")
        return

    ports = parse_ports(args.ports)

    print(f"[*] 目标：{args.host} ({target_ip})")
    print(f"[*] 端口数量：{len(ports)}")
    print(f"[*] 超时：{args.timeout}s")
    print(f"[*] 线程数：{args.workers}")
    print("-" * 50)

    open_ports = scan_ports(target_ip, ports, args.timeout, args.workers)

    print("-" * 50)
    if open_ports:
        print(f"[+] 开放端口：{', '.join(map(str, open_ports))}")
    else:
        print("[-] 未发现开放端口")


if __name__ == "__main__":
    main()

保存为 port_scanner.py 后，可以这样使用：

python3 port_scanner.py 127.0.0.1 -p 1-1024 -t 0.5 -w 200

扫描常见端口：

python3 port_scanner.py example.com -p 21,22,80,443,3306,3389,6379,8080

扫描指定范围：

python3 port_scanner.py 192.168.1.1 -p 8000-9000 -t 0.3 -w 300

七、完整代码整理
#

把上面的内容合并，就是一个可以直接运行的版本：

#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import argparse
import socket
from concurrent.futures import ThreadPoolExecutor, as_completed


def parse_ports(port_str: str) -> list[int]:
    """解析端口字符串，支持 80,443,8000-8100 这种格式。"""
    ports = set()

    for part in port_str.split(","):
        part = part.strip()
        if not part:
            continue

        if "-" in part:
            start, end = part.split("-", 1)
            start, end = int(start), int(end)
            if start > end:
                start, end = end, start
            ports.update(range(start, end + 1))
        else:
            ports.add(int(part))

    return sorted(p for p in ports if 1 <= p <= 65535)


def scan_port(host: str, port: int, timeout: float = 1.0) -> tuple[int, bool]:
    """扫描单个 TCP 端口，返回 (端口, 是否开放)。"""
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        try:
            result = s.connect_ex((host, port))
            return port, result == 0
        except (socket.timeout, OSError):
            return port, False


def scan_ports(host: str, ports: list[int], timeout: float = 1.0, workers: int = 100) -> list[int]:
    """多线程扫描多个端口，返回开放端口列表。"""
    open_ports = []

    with ThreadPoolExecutor(max_workers=workers) as executor:
        future_to_port = {
            executor.submit(scan_port, host, port, timeout): port
            for port in ports
        }

        for future in as_completed(future_to_port):
            port, is_open = future.result()
            if is_open:
                open_ports.append(port)
                print(f"[+] {host}:{port} 开放")

    return sorted(open_ports)


def main():
    parser = argparse.ArgumentParser(description="Python + socket TCP 端口扫描器")
    parser.add_argument("host", help="目标主机，例如 127.0.0.1 或 example.com")
    parser.add_argument(
        "-p",
        "--ports",
        default="1-1024",
        help="端口范围，例如 80,443,8000-8100，默认 1-1024",
    )
    parser.add_argument(
        "-t",
        "--timeout",
        type=float,
        default=1.0,
        help="连接超时时间，单位秒，默认 1.0",
    )
    parser.add_argument(
        "-w",
        "--workers",
        type=int,
        default=100,
        help="并发线程数，默认 100",
    )

    args = parser.parse_args()

    try:
        target_ip = socket.gethostbyname(args.host)
    except socket.gaierror:
        print(f"[-] 无法解析主机：{args.host}")
        return

    ports = parse_ports(args.ports)

    print(f"[*] 目标：{args.host} ({target_ip})")
    print(f"[*] 端口数量：{len(ports)}")
    print(f"[*] 超时：{args.timeout}s")
    print(f"[*] 线程数：{args.workers}")
    print("-" * 50)

    open_ports = scan_ports(target_ip, ports, args.timeout, args.workers)

    print("-" * 50)
    if open_ports:
        print(f"[+] 开放端口：{', '.join(map(str, open_ports))}")
    else:
        print("[-] 未发现开放端口")


if __name__ == "__main__":
    main()

九、进一步优化建议
#

1. 使用 asyncio 替代多线程
#

如果不想管理线程池，可以用 asyncio 实现更高并发的异步扫描：

import asyncio


async def scan_port(host: str, port: int, timeout: float = 1.0) -> tuple[int, bool]:
    try:
        reader, writer = await asyncio.wait_for(
            asyncio.open_connection(host, port),
            timeout=timeout,
        )
        writer.close()
        await writer.wait_closed()
        return port, True
    except (asyncio.TimeoutError, OSError):
        return port, False

2. 增加 Banner 抓取
#

端口开放不代表知道服务。可以连接后读取一小段 Banner：

def grab_banner(host: str, port: int, timeout: float = 1.0) -> str:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        try:
            s.connect((host, port))
            s.sendall(b"\r\n")
            data = s.recv(1024)
            return data.decode(errors="ignore").strip()
        except (socket.timeout, OSError):
            return ""

3. 控制并发与超时
#

并发太高可能导致：

  • 本地文件描述符耗尽；
  • 目标防火墙封禁你的 IP；
  • 网络拥塞，结果不准。

建议从 workers=100、timeout=0.5 开始，根据网络环境调整。

4. 支持 IPv6
#

socket.AF_INET 只支持 IPv4。如果需要 IPv6，可以使用 socket.getaddrinfo() 获取地址族，再动态创建 socket。

5. 结果输出为 JSON 或 CSV
#

如果要把扫描结果接入其他系统，可以增加 --json 或 --csv 参数，把 open_ports 序列化输出。

6. 随机化扫描顺序
#

部分入侵检测系统会识别顺序扫描行为。随机打乱端口顺序可以降低被简单规则发现的概率，但这并不能让未授权扫描变得合法。

十、法律与道德提醒
#

端口扫描本身是一种技术手段，但使用它必须遵守边界：

  • 只扫描你自己拥有的主机；
  • 只扫描你获得明确书面授权的目标；
  • 不要在公共网络、云平台、校园网、公司内网中随意扫描；
  • 不要将扫描结果用于入侵、破坏或数据窃取；
  • 了解并遵守当地法律法规。

技术本身没有善恶，关键在于使用它的人。

十一、总结
#

这篇文章从 socket.connect_ex() 出发，完成了一个 TCP 端口扫描器：

  1. 单端口扫描；
  2. 多端口循环；
  3. 多线程并发；
  4. 命令行参数解析；
  5. 完整可运行代码；
  6. 后续优化方向。

它不是一个替代 nmap 的完整工具，但非常适合理解 TCP 连接、socket 编程和并发扫描的基本原理。等你掌握这些之后，再去看更专业的扫描器源码，会轻松很多。
